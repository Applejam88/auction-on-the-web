# 系辦惜物拍賣會

可離線執行的現場拍賣、競標者名冊、得標賓果與結算管理工具。

- **主程式：** `auction-v1.1.html`
- **需求基準：** v1.1，包含後續介面調整、特別獎設定及批次貼上姓名功能。
- **文件更新日期：** 2026 年 10 月 13 日。

## 1. 開啟與使用

1. 將 `auction-v1.1.html` 下載到電腦上的固定資料夾。
2. 用 Google Chrome 或 Microsoft Edge 的一般瀏覽模式開啟 HTML。
3. 在「資料與說明」設定活動名稱。
4. 依首頁的「準備、拍賣、結算」操作流程進行活動。

主程式內含 HTML、CSS 與 JavaScript，沒有 CDN、遠端套件或網路服務依賴。不需要安裝套件、啟動伺服器或建立帳號。

`README.md` 是說明文件，不是程式執行所需的依賴檔案。可與 HTML 放在同一資料夾保存。

> **活動資料不會寫入 HTML 檔案。** 商品、照片及紀錄保存在瀏覽器的 IndexedDB。單純複製 HTML 到另一台電腦，不會連同活動資料一起複製；跨電腦使用需匯出、還原 JSON 備份。

## 2. 主要頁面

| 頁面 | 用途 |
|---|---|
| 活動首頁 | 查看商品數、成交總額、活動進度與操作流程 |
| 商品管理 | 新增商品、上傳照片、設定起標價，以及設定特別獎 |
| 競標控制台 | 開拍、記錄出價、撤銷出價、確認成交、流標及重拍 |
| 競標者名冊 | 單筆新增、批次貼上姓名、搜尋及查看得標清單 |
| 拍賣賓果 | 建立與鎖定卡片、查看標記與排名、結算特別獎 |
| 結算管理 | 查詢成交紀錄、登記付款與領取、更正或撤銷成交 |
| 資料與說明 | 活動設定、投影選擇、CSV 匯出、JSON 備份還原及操作歷史 |

## 3. 活動準備

### 商品與特別獎

在「商品管理」按「＋ 新增商品」，填寫名稱、描述、起標價及備註，並視需要上傳照片。商品編號由系統自動建立。

- 照片格式：PNG、JPEG、WebP。
- 每張照片最大 10 MB；建議先縮小照片，以減少儲存及備份容量。
- 金額以新臺幣整數元計算；目前輸入範圍為 0–1,000,000,000 元。
- 商品已有拍賣歷史後，起標價固定；名稱、描述及照片仍可編輯。
- 賓果未鎖定且商品沒有拍賣歷史時，才提供商品刪除操作。

按「＋ 新增特別獎」設定**一份賓果特別獎**的名稱、說明與照片；設定後可再次編輯。特別獎不參與拍賣，不增加商品數或賓果格子，於特別獎投影畫面展示。

### 競標者名冊

競標編號使用 `001`–`999`，每個編號只能對應一筆名冊資料。可活動前建立，也可在競標控制台現場新增。

#### 單筆新增

在「競標者名冊」按「＋ 新增競標者」，填寫編號、姓名或暱稱及備註後儲存。已有競標或成交紀錄的競標者不能直接刪除。

#### 批次貼上姓名

1. 按「批次貼上姓名」。
2. 貼上姓名清單，**每行一位**；可直接複製 Excel 的單一姓名欄。
3. 按「預覽編號」，核對新增人數、姓名及編號。
4. 按「確認新增 … 位競標者」才會正式儲存。

例如：

```text
王小明
陳小華
林小美
```

系統依貼上順序，從**最小未使用編號**開始分配。例如名冊已有 `001`、`003`，下一批會使用 `002`、`004`、`005`。

- 自動略過空白行與姓名前後空白。
- 預設略過與現有名冊或本次清單相同的姓名，並在預覽提供略過清單。
- 若不同人同名，取消勾選「略過…重複的姓名」，即可為各行建立不同編號。
- 每個姓名最多 100 字；不要同時貼入 Excel 的其他欄位。
- 預覽後修改內容或重複姓名選項，須重新預覽。
- 編號不足或資料異常時，不會先儲存部分名冊。

### 建立並鎖定賓果卡

1. 完成要納入賓果的商品資料。
2. 到「拍賣賓果」按「產生／重新排列」。
3. 檢查商品編號及重複格子。
4. 按「確認並鎖定」。

**正式開拍前必須鎖定賓果卡。** 鎖定後不能重新排列或修改格子；鎖定前新增或刪除商品後，請重新產生卡片並檢查。

## 4. 現場拍賣

1. 進入「競標控制台」，選擇拍賣商品。
2. 按「開始拍賣」，商品進入拍賣中狀態。
3. 輸入競標編號及出價金額，再按「記錄出價」。
4. 持續記錄新出價；若記錯，可按「撤銷上一筆」。
5. 主持人人工確認無人再加價後，按「確認成交」並核對商品、得標者及成交金額。
6. 若不成交，按「標記流標」。流標商品可「重新上架並開拍」。

### 出價規則與提醒

- 競標編號欄預設空白，競標者必須已存在於名冊。
- 第一筆有效出價不得低於起標價；之後每筆至少高於目前最高有效價 1 元。
- `＋10`、`＋50`、`＋100` 只填入金額，**仍須按「記錄出價」**。
- 快捷加價以最高有效價為基準；尚無有效出價時，以起標價為基準。
- 一次只能開拍一件商品。
- 沒有有效出價時不能成交；系統會依編號是否已填寫，提示檢查競標編號或是否已記錄出價。
- 撤銷出價會保留歷史，並恢復前一筆最高有效價。
- 流標重拍會建立新輪次，保留先前輪次及出價紀錄。

全部商品均已成交或流標後，可在首頁建議操作流程，或競標控制台「目前狀態」區域按「結束拍賣」。確認後，主持人畫面會自動跳轉至「拍賣賓果」。

## 5. 賓果與特別獎規則

### 卡片與標記

全場共用相同排列，卡片邊長為：

```text
max(2, 向上取整(√納入商品數))
```

例如 14 件商品使用 4×4 卡片；每件商品至少出現一次，剩餘 2 格以既有商品編號補足。

| 規則 | 說明 |
|---|---|
| 得標才標記 | 曾喊價但未得標，不獲得標記 |
| 重複格子 | 得標一次，同商品編號的所有格子一起標記 |
| 完整連線 | 橫線、直線及兩條對角線，整條均標記才算完成 |
| 最佳單線 | 所有有效線中，已標記格數最多的一條 |
| 得標件數 | 依有效成交商品件數計算，重複格子不增加件數 |
| 鎖定後新增商品 | 可正常拍賣，不新增賓果格子，但得標件數仍參與排名比較 |
| 流標後重拍 | 原本納入卡片的商品仍保有賓果資格 |
| 成交撤銷或更正 | 依目前有效成交重新計算標記及排名 |

### 排名與結算

只有至少得標一件商品的競標者有特別獎資格。

| 全場成績 | 比較順序 |
|---|---|
| 至少一人完成完整連線 | 完整連線數 → 得標件數 → 同分抽籤 |
| 沒有人完成完整連線 | 最佳單線格數 → 得標件數 → 同分抽籤 |

結束拍賣後，按「結算特別獎／同分抽籤」。唯一最高排名者直接公布；仍同分時，只從並列第一者隨機抽出一位，保存候選人、時間與結果。全場無人得標時不產生得獎者。

已有正式結果時不能重複抽籤。後續更正得標者或成交價、撤銷成交、重新開拍或新增商品，會使既有特別獎結果失效；完成相關處理後須重新結算。

## 6. 投影展示

1. 在主持人視窗按「開啟投影」。若未出現視窗，請允許瀏覽器彈出視窗。
2. 將投影視窗移至第二螢幕或投影機。
3. 在投影視窗按「全螢幕」。
4. 保持主持人控制台開啟，讓兩個視窗持續同步。

投影可顯示商品與競標、賓果卡、排行榜及特別獎。畫面採明亮配色，成交時有慶祝效果；投影顯示競標編號，不顯示名冊姓名。

### 投影賓果卡

在「拍賣賓果」或「資料與說明」選擇全場共用卡或指定競標者，再按「投影所選賓果卡」，確認提醒後才更新投影。只改選擇不會立即切換觀眾畫面。

- 點一下格子可翻面看商品名稱，再點一次回到商品編號。
- 共用卡翻面另顯示「得標者編號」；商品與得標者使用不同標籤及配色。
- 未成交或流標商品會顯示相應狀態，不會列出已撤銷成交的得標者。
- 共用卡淡綠格子代表商品已成交，**不代表任何個人完成賓果連線**。
- 個別競標者卡只標記該競標者的得標商品，並顯示最佳單線及完整連線。
- 翻牌是展示效果，不會更改競標或計分資料。

**返回競標控制台會自動將投影切回商品競標畫面。** 因此投影排行榜或賓果卡時，若希望維持該展示，請留在相應的管理頁面操作。

## 7. 付款、領取及成交更正

在「結算管理」可依商品、競標者、付款及領取狀態查詢。

- 「已付款」與「已領取」分開勾選及保存。
- 「更正／備註」可更換得標者、成交價或修改備註。
- 改得標者或成交價須填寫原因，會重設付款與領取狀態，並保留更正歷史。
- 更正不改寫原始出價紀錄。
- 「撤銷成交」須填寫原因；商品回到待拍賣，成交及拍賣輪次保留撤銷歷史。
- 已付款或已領取的商品撤銷前，須由工作人員另行核對退款及商品歸還；本工具不執行金流。

## 8. 報表與完整備份

### CSV 報表

在「資料與說明」可個別下載以下報表，或按「一鍵下載全部 CSV（ZIP）」取得一個 ZIP，解壓縮後得到全部七份 CSV。

| 報表 | 主要內容 |
|---|---|
| 商品與成交 | 商品資料、狀態及目前成交結果 |
| 全部出價 | 商品、輪次、出價者、金額、時間與撤銷狀態 |
| 競標者名冊 | 編號、姓名及備註 |
| 付款與領取 | 成交資料、姓名、付款領取及撤銷狀態 |
| 賓果排名 | 名次、連線、最佳單線、得標件數及正式得獎標記 |
| 特別獎紀錄 | 候選人、結果、抽籤方式、失效資訊及獎品名稱 |
| 賓果卡排列 | 每格的列、欄、商品編號及鎖定資訊 |

CSV 使用 UTF-8 BOM、引號跳脫及公式前綴防護。Excel 若將 `001` 自動顯示成 `1`，請用資料匯入功能開啟，將編號欄設為「文字」。CSV 不含照片，不能代替完整備份。

### JSON 備份與還原

「JSON 備份」或「下載 JSON 完整備份」包含活動設定、商品與照片、特別獎、名冊、所有拍賣輪次與出價、成交、付款領取、賓果配置、抽籤及操作歷史。

還原步驟：

1. 先下載目前活動的 JSON 備份。
2. 在「資料與說明」選取要還原的 JSON。
3. 系統驗證格式、版本及資料一致性，顯示摘要。
4. 核對後按「確認完整還原」。

還原會**整批覆蓋目前活動，不會合併**。目前還原檔案大小上限為 200 MB。舊版 v1.1 備份可匯入目前版本；新版備份請優先搭配相同新版程式還原。

建議在活動開始前、重要結算後、活動結束後各備份一次，並將備份另存至適當的外部儲存位置。更換 HTML、移動檔案、換電腦或換瀏覽器前也應先備份。

## 9. 常見問題

| 情況 | 處理方式 |
|---|---|
| 無法開始拍賣 | 先產生並鎖定賓果卡；若已有商品拍賣中，先結束該商品 |
| 出價無法記錄 | 檢查名冊編號、整數金額、起標價及是否高於最高有效價 |
| 按成交卻沒有有效出價 | 先輸入競標編號並按「記錄出價」；不成交則使用流標 |
| 批次貼上沒有新增姓名 | 查看略過清單；若為不同人同名，取消略過重複並重新預覽 |
| 批次預覽後不能儲存 | 內容或活動資料可能已異動，重新預覽編號後再確認 |
| 不能結束拍賣 | 仍有待拍賣或拍賣中商品，須先全部成交或流標 |
| 投影沒有出現 | 允許彈出視窗，再按「開啟投影」 |
| 投影同步中斷 | 保持主持人視窗開啟；關閉投影後由控制台重新開啟 |
| 投影排行榜突然切回商品 | 返回競標控制台會自動切回，這是目前的操作設計 |
| 重新開啟後資料不見 | 確認檔案路徑、瀏覽器及使用者設定檔是否相同，或還原 JSON 備份 |
| 儲存失敗 | 依提示檢查瀏覽器儲存空間或另一控制台的異動；失敗操作不視為已完成 |
| 特別獎結果失效 | 先確認成交更正或重拍內容，再完成活動並重新結算 |

「載入示範資料」會覆蓋目前活動；「建立全新活動」會清空目前資料，並要求輸入確認文字。使用前先下載 JSON 備份。

## 10. 資料保存與使用限制

- IndexedDB 是本機保存，不是跨裝置備份，也不保證清除瀏覽器資料後仍可恢復。
- 瀏覽器對 `file://` 的儲存及視窗行為可能不同；請在活動電腦上試跑。
- 建議只使用一個主持人控制台；另開的投影視窗用於展示。若舊控制台嘗試覆蓋較新的資料，系統會拒絕寫入並重新載入。
- 本工具沒有多人網路競標、登入系統、線上付款或雲端同步功能。
- 備份及部分 CSV 含姓名和活動紀錄，請依活動的資料管理方式保存及提供。

## 11. 修改程式與技術說明

所有程式都在 `auction-v1.1.html`，可用文字編輯器修改。修改前請另存原始 HTML 及 JSON 備份。

| 部分 | 實作 |
|---|---|
| 介面 | 原生 HTML、內嵌 CSS 與 JavaScript |
| 本機資料庫 | IndexedDB：`department-reuse-auction-v1`，物件儲存區 `state`，活動鍵 `event` |
| 資料保存 | 整份活動狀態以交易寫入，並檢查修訂號以避免舊資料覆蓋 |
| 投影入口 | 同一 HTML 的 `#projection` 模式，由主持人開啟 |
| 投影同步 | 視窗 `postMessage` 傳送狀態與心跳訊息 |
| 排名 | `rankings()` 依有效成交資料計算 |
| 資料驗證 | `validate()`，含商品、輪次、成交、賓果及特別獎一致性檢查 |
| 批次姓名 | `planBulkBidders()` 產生新增前預覽 |
| CSV 與 ZIP | `csv()`、`csvAll()` 及內嵌 ZIP 封裝，沒有外部套件 |
| 開發檢查入口 | `window.AuctionCore` 暴露部分資料、驗證與計分函式 |

目前 JSON 資料格式的 `version` 為 `1`，與文件的 v1.1 標示是不同用途的版本欄位。修改資料結構時，應一併檢查驗證、儲存、備份還原及舊資料相容性，不宜直接刪改既有歷史。

README 未列出的外部資源或測試工具，不是主程式執行的必要條件。

## 12. 測試狀態與活動前試跑

已完成核心規則及模擬 DOM／IndexedDB 操作測試，涵蓋出價與撤銷、成交與流標重拍、賓果計分、抽籤、更正、投影訊息、批次名冊、資料保存、備份相容性及 ZIP 解壓驗證。

**尚未完成實際瀏覽器與實體雙螢幕驗收。** 活動前請用測試資料確認：

- 斷網後可開啟與操作，商品照片正常顯示。
- 儲存後重新整理、關閉再開啟，資料仍可讀取。
- 完成一輪出價、撤銷、成交、流標及重拍。
- 投影同步、全螢幕、賓果翻牌與成交效果正常。
- 返回競標控制台時，投影切回目前商品。
- 全部商品結標後能結束拍賣，並進行特別獎結算。
- CSV／ZIP 可開啟，JSON 可完整還原照片與紀錄。

試跑結束後，先備份需要保留的資料，再建立正式活動。
